# 串口占位协议（非恢复事实）

> **重要**：该协议是为了证明分层可落地而设计的占位协议。它不是从原始项目中恢复
> 出来的协议，也没有在真实机器人上验证。真机接入前必须用 G1/G2 的答案替换它。

## 传输

- 物理层：pyserial（USB 转串口）
- 默认波特率：115200 8N1
- 帧头：`AA 55`
- 长度：1 字节，仅 payload 长度，最大 255
- 校验：CRC-16/CCITT-FALSE，多项式 `0x1021`，初值 `0xFFFF`，小端写入
- 格式：`AA 55 LEN PAYLOAD[LEN] CRC_LO CRC_HI`

## 占位 payload（ASCII JSON）

发送速度：

```json
{"t":"v","l":0.1,"a":-0.2}
```

字段含义为线速度 m/s、角速度 rad/s。

停车、急停、清除急停分别发送：

```json
{"t":"s"}
{"t":"e"}
{"t":"c"}
```

遥测：

```json
{"t":"t","x":0.0,"y":0.0,"h":0.0,"l":0.0,"r":0.0,"ts":1.23,"e":false,"f":null}
```

字段含义：位姿 x/y（m）、朝向 h（rad），左右轮速（rad/s），时间戳（s），急停标志，
故障文本。

## 替换方法

1. 实现 `robot_recon.hal.protocol.TelemetryCodec`。
2. 在 `SerialRobotDevice(..., codec=YourCodec())` 中注入。
3. 若真实协议不使用 `AA 55 + CRC-16`，同步替换 `framing.py`；设备层与业务层无需改动。
4. 用真实设备回放/硬件在环测试验证编码、解码、超时和急停。
5. 在 `docs/OPEN_QUESTIONS.md` 记录协议来源和验证日期。

## 安全要求

- 真机首次联调必须架空轮子或置于空旷区域。
- 必须有独立于本程序的物理急停。
- 先只读遥测，再以极低速度测试单轴动作。
- 开始时不要使用自动航点任务，先手动发送单条速度并确认方向。
- 任何协议错误都应按“不安全”处理：停车，而不是继续重试运动。
